# Состояние проекта: SmallCaps Tool (C++ Native)

## Структура
- `main.cpp`: Нативная Win32 C++ реализация (ультралегкий бинарник ~218 КБ, потребление памяти ~1-2 МБ, высвобождение при сворачивании до сотен КБ).
- `resource.rc`: Ресурсы Windows PE с вшитой иконкой (ID `1`).
- `app_icon.ico`: Иконка приложения для EXE, заголовка и трея.
- `.github/workflows/build.yml`: Автосборка C++ бинарника на GitHub Actions и публикация релизов.
- `BUILD.md`: Инструкция по сборке C++ версии.

## Принятые решения
- Язык: Нативный C++17 (Win32 API) для ультранизкого потребления ресурсов (ПК: Pentium P4600, 4GB RAM).
- UI: Глубокая тёмная тема (Modern Dark Theme), полностью кастомная отрисовка контролов (`BS_OWNERDRAW` + `WM_DRAWITEM` с двойной буферизацией и сглаженными углами, hover-эффекты через `TrackMouseEvent`, чистые поля ввода без классических белых/серых фасок).
- Лимиты ресурсов: Windows Job Object (CPU hard cap 20%, RAM hard cap 256 МБ, приоритет `BELOW_NORMAL_PRIORITY_CLASS`).
- Высвобождение памяти: при сворачивании в трей вызывается `EmptyWorkingSet` и `SetProcessWorkingSetSize`, сбрасывая занятую физическую память.
- Автораспознавание: кириллица <-> Small Caps кириллица, латиница <-> Small Caps латиница, mixed -> оба, Small Caps -> обычный текст.
- Стили текста: Small Caps (`ᴀʙᴄ`) и Широкий Моноширинный (`ＡＢＣ`).
- Глобальные хоткеи: `Ctrl+Alt+S` (конвертация буфера на лету со звуковым сигналом), `Ctrl+Alt+W` (показать/скрыть окно).
- Окно: кнопка Always on Top `📌`, сворачивание в фон/трей по `[X]` и `Esc`.
- История: хранение последних записей с копированием в 1 клик.
- Токены и секреты НЕ сохраняются в файлы проекта.
